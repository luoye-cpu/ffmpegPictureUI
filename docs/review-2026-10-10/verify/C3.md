## 3 A3 N1 vs C3 静5 的裁决（HDR 走表还是走解析）

**判据逐条列出（我实读 HEAD 源码）**

`ColorKernels.cs:503-504`（16-bit 主出口，走表 = `fast`）：

```csharp
bool fast = eotf != null && oetf != null && Math.Abs(scale - 1.0) < 1e-12 && !toneOn
            && !spec.SrcIsHlgScene && !gamut;
```
查 6 项：① src 表非空 ② dst 表非空 ③ **`LinearScale`**（`scale`，:477）==1 ④ `!toneOn` ⑤ `!SrcIsHlgScene` ⑥ `!gamut`。
**不查**：`EncodeScale`（:539 `encScaleOn` 只在解析路 :568-571 生效）、`DstIsHlgScene`（:540 `dstHlg` 只在 :572-580 生效）。

`ColorKernels.cs:696-699`（8-bit 出口，走表 = `tbl`）：

```csharp
if (tbl && (scaleOn || toneOn || encScaleOn || srcHlg || dstHlg)) { eF = null; oF = null; tbl = false; }
```
查 5 项算子：`LinearScale`/`toneOn`/`**EncodeScale**`/`srcHlg`/`**dstHlg**`。**不查** `gamut`（该路只有一个循环，GMO 在两端之间照跑）。

**生产侧 nits 换算（我实读 `ColorTransformPlan.cs:431-451`）**：`refWhite=203`；`LinearScale = srcNits/refWhite` **仅在 srcNits≠203 时置位**；`EncodeScale = refWhite/dstNits` 仅在 dstNits≠203 时置位；`SrcIsHlgScene`/`DstIsHlgScene` 按曲线 Kind 置位。

⇒ 于是两类任务分道扬镳：

| 任务类 | `LinearScale` | `EncodeScale`/`dstHlg` | `fast`（16-bit） | 实际执行 |
|---|---|---|---|---|
| **HDR 源**（PQ→sRGB、HLG→sRGB、PQ→HLG，含 tonemap/GMO） | 49.26 / 4.926（≠1） | — | **false** | **解析路**（每像素 6 次求值/含 pow）＝ C3 静5 与 实3 的那一格 |
| **SDR 源 → HDR 目标**（sRGB→PQ、sRGB→HLG，`--bit-depth 16` + png/tiff/jxl） | **恰为 1** | **0.0203 / HLG 逆 OOTF** | **true**（前提：≥256,000 px、无 GMO、无 tonemap ⇒ `TablesFor` `:1087-1090` 照建表） | **表路，且整段跳过 EncodeScale/逆 OOTF** ＝ A3 N1 的错曝 49× |

**裁决（三点）**

1. **两条不矛盾，也不是"一条把条件读反了"**：`fast` 只查 `LinearScale`（源侧 nits），完全不查 `EncodeScale`/`dstHlg`（目标侧 nits）。C3 静5 描述的关闭机制 ✓ 真；A3 N1 描述的漏判据 ✓ 真。它们是**同一副判据的两个缺口**（一个关得太多、一个漏得太少），D1 §4 的"同一个判据的两面"归纳正确。
2. **C3 静5 的措辞是这轮唯一的实质越界**："**所有 HDR 任务**必走解析路" 不成立，成立的是"**所有 HDR 源任务**"。这个措辞把 SDR→HDR 目标那一格划出了视野 —— 而那一格恰是 A3 N1 的触发面。所以 C3 静5/实3 **不能反过来给 A3 N1 背书**，它只是没与之冲突。（C3 正文 `:48` 处甚至写过"与 A3 N1 同族互证"，方向对、依据弱：`bench.cs:89-94` 的三个用例 dst 全是 sRGB ⇒ bench 里**根本没有 SDR→HDR 目标那一格**，实测档对 N1 既不能证真也不能证伪。）
3. **A3 N1 是真缺陷**：可达链我独立复现到 `ToSpec`（`ClampLinearBeforeEncode = true` 恒在 `:408/:417`）+ `:1087` 阈值（表照建）+ `:503-504`（fast 照真）+ 快循环 `:512-526`（无 `encScaleOn`/`dstHlg` 分支）。**HEAD 未被修**（`git log` 最近一次动 `ColorKernels.cs` 是 `123f2bb`，2026-10-05，只补了 8-bit 那侧）。唯一没被任何 lane 给出的是端到端读数（A3 自己标 `未测`）。
