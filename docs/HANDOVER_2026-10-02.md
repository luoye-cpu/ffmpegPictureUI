## 五、本批我踩到/写错的（都已在文件里留痕，别再抄错的）

- **把"合法出口"写成"缺陷复现"**：第 65 条曾把 `--jpeg-dct float` 标成"面板值域被编码器拒绝 = A-20 复现"。
  实况：float 早在 A-20 修复时从下拉移除（`MainWindow.xaml:725-728` 只剩 auto/int/fastint），
  实测 `lo rc=0 / hi rc=1` = 响亮拒绝 ⇒ 改记 `WARN 越界被拒(不计入)`，且**没被拒时不许直接记活**。
- **不判红的桶不许用 `FAIL` 前缀**：运行器把 `^ *FAIL|^FAIL` 当失败明细回显 ⇒ 绿的一步下面挂红字。
- **套件必须有一条 `PASS=n` 汇总**：运行器的零断言闸只认 `PASS\s*=\s*(\d+)`（取最大值），
  只有"合计=N"的措辞会被记成"可能一条都没跑"。
- **接进清单是四件事不是两件**：`$expectedScriptCount` + 三种散文形态（第 ⑰ 针逐形态与常量对账）+
  `docs/TESTING.md` §3.5 + `docs/HANDOVER.md` 的清单行。验它最便宜的跑法 =
  `pwsh -File _run-step3-gates.ps1 -Scripts verify-ps-compat.ps1 -Probes selftest`（条数锁在子集解析**之前**执行）。
- **A30 的行号锚会被任何一次产品编辑挪走**：`_lib-matrix.ps1` 两处 pin 从 763/715 → 796/748（+33）。
  抬号前 `grep -n` 复核实况 + 确认字面量全文件唯一；改一次产品代码就要重核一次。
- **结构锁会咬合法的产品改动**，红不一定指产品：`RunAsync` 24→25（我加了一条回退支）、
  cjk UI 面 837→840（两条终态标签 + 一个 `"默认"` 比对常量落进 UI 桶，属口径已知局限）。
  两处都按"显式登记理由/日期/行号"的既有流程处理，**没有**放宽任何判据。
- **新调用点不要重复点心跳**：#15-b 起心跳是默认（opt-out），显式 `heartbeat: true` 会让
  "字面量出现次数 == 已标签站点数"那条断言红；且**注释里也别写这两个词**（该断言按全文正则计数）。
- **`7z l` 用反斜杠打印路径**；**MSBuild 拷贝保留源时间戳 ⇒ 产物 mtime 会假旧**，
